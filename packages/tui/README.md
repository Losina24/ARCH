# @losina/arch-terminal

`arch-terminal` — the ARCH terminal UI. A terminal client for the ARCH daemon: create runs, follow the Architect's plan and grilling questions, watch task progress, and approve or refine work in progress.

## Install

```bash
npm install -g @losina/arch-terminal
```

## Usage

```bash
arch-terminal
```

Requires the ARCH daemon (`@losina/arch-cli`) to be running against the target repository. See the [ARCH README](https://github.com/Losina24/ARCH#readme) for the full orchestration model.
